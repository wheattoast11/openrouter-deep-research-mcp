# Music Workflow Agent Harness

Harness for running music production workflow experiments with multi-context coherence tracking and Aha skill detection.

## Features

- Multi-context state tracking (DAWs, email, distribution platforms)
- Aha skill detection and logging (emergent anticipation capability)
- Kuramoto coherence measurement across contexts
- Integration with openrouter-deep-research-mcp
- Crystallization pattern detection

## Emergent Capability: Coherent Multi-Context Orchestration

The specific emergent capability being isolated and tracked:

**Definition**: The ability to maintain semantic coherence while orchestrating actions across multiple distinct contexts (DAWs, services, file systems) with 1M+ token working memory.

**Aha Skill**: The instant the agent recognizes that a technical action in Context A has semantic implications for Context B without being told.

## Quick Start

```bash
# Run simulation
python music_workflow_harness.py --project my_track --daws ableton logic --simulate

# Run parallel experiments
python experiment_runner.py --output ./outputs --num 5
```

## Metrics Tracked

1. **Coherence Score** - Kuramoto order parameter across context phases
2. **Anticipation Rate** - Correct unprompted cross-context predictions
3. **Drift Awareness** - Self-correction rate before user intervention
4. **Aha Latency** - Speed of correct anticipations

## Integration

This harness integrates with:
- `agent_zero_trainer` package (primitives, rewards, pipeline)
- `openrouter-deep-research-mcp` (research agent)
- vLLM serving for QwenLong-L1.5-30B-A3B
